Why these, not a prompt you'd write yourself

You can ask Claude to write "a skill for app store copy" in thirty seconds. These aren't that. They're built from actually hitting the wall a few times first — the real 30-character subtitle limit, the real 100-character keyword field, the "don't fabricate a testimonial, write the prompt to collect one instead" rule. That's not prose, it's accumulated correction.

Every skill here was tested against a real shipped app before it went in this repo, not a toy example — the onboard-explainer skill's actual first output is a live onboarding doc in a real production codebase.

Questions

Do I need to know how to code?
No — installing is one copy command, and using a skill after that is just asking Claude Code for what you want in plain English.
Does this work with anything besides Claude Code?
Built for Claude Code's skills system specifically — that's what the install step targets.
What if Claude Code changes and these stop working?
Skills are plain markdown instructions, not version-locked code — built to keep working across updates. Watch the GitHub repo for revisions as conventions evolve.
Why free skills at all — what's the catch?
No catch. They're genuinely useful on their own, and they're also the easiest way to judge whether the paid kits are worth it before either exists as a purchase.
